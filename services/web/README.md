# Yashika Hidau Portfolio

Responsive, static portfolio built with Next.js App Router, TypeScript, Tailwind CSS, Framer Motion, and Lucide React.

## Run locally

From the workspace root, change into the frontend folder, then install and run:

```sh
cd services/web
npm install
npm run dev
```

Open the local URL printed by Next.js (usually `http://localhost:3000`).

## Production build

```sh
npm run build
npm run start
```

The site is frontend-only and does not require a database, API, authentication, or environment variables.
